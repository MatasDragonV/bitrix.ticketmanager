# bitrix.ticketmanager — Управление обращениями

Модуль для Битрикс: расширенный список обращений техподдержки с фильтрами и массовым удалением спама.

## Установка

1. Скопировать папку `bitrix.ticketmanager` в `/bitrix/modules/`
2. Зайти: **Административная панель → Настройки → Модули**
3. Найти «Управление обращениями (Ticket Manager)» и нажать **Установить**
4. Скопировать файл страницы в админку:
   ```
   cp bitrix/modules/bitrix.ticketmanager/admin/ticket_list.php \
      bitrix/admin/ticket_manager_list.php
   ```
5. После установки пункт **«Управление обращениями»** появится в меню **Сервисы**

## Возможности

- **Фильтры**: по ID, заголовку, email автора, маске email (`*@spamsite.ru`), дате от/до, признаку спама (заголовок без типа)
- **Таблица** с пагинацией (25 / 50 / 100 / 200 на страницу), кликабельным ID для открытия обращения
- **Массовое удаление выбранных** через чекбоксы
- **Удаление всех по фильтру** с подтверждением в модальном окне
- **Экспорт в CSV** отфильтрованных обращений

## Признак спама

Обращение считается спамом если заголовок заканчивается на `Тип: ` (пустой тип).  
Это характерно для компонента `iblock.wizard`, когда пользователь не выбрал тип обращения.

## Требования

- Битрикс CMS любой редакции
- Модуль «Техническая поддержка» (`support`) должен быть установлен
- PHP 8.0+
